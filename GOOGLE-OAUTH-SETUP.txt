BabiTk — Google login + Google Calendar
=======================================

Live stack: GitHub Pages + Supabase Edge (not Convex / not Fastify).

1) Google Cloud Console → Credentials → OAuth client ID (Web application)

2) Authorized JavaScript origins:
   http://localhost:5173
   https://erezbabayan.github.io

3) Authorized redirect URIs (both):
   https://ghibfuinantybqidwadj.supabase.co/auth/v1/callback
   https://ghibfuinantybqidwadj.supabase.co/functions/v1/google-calendar/callback

4) Enable the Google Calendar API on the same project.

5) Set Edge secrets (not in git):
   GOOGLE_CLIENT_ID=....apps.googleusercontent.com
   GOOGLE_CLIENT_SECRET=GOCSPX-...

   npx supabase secrets set --project-ref ghibfuinantybqidwadj \
     GOOGLE_CLIENT_ID=... GOOGLE_CLIENT_SECRET=...

   The same values can also live in GitHub Actions secrets so deploy-supabase-functions.yml syncs them.

6) After deploy, health check:
   https://ghibfuinantybqidwadj.supabase.co/functions/v1/google-calendar/health

   configured=true means OAuth is ready. Then Settings → Google Calendar → חבר.

What syncs: dated actionable BabiTk tasks (1-hour events, Asia/Jerusalem, primary calendar).
Notes without a date stay out of the calendar. Delete / convert to note / clear the date removes the event.
